Berikut merupakan tugas tentang membuat dictionary sebuah buku dan menerapkan konsep CRUD (create, read, update, delete).
Program ini dibuat untuk mengelola data buku dalam dictionary di python. data buku terdiri dari Judul, Penulis dan Tahun Terbit.
Program dirancang dengan menggunakan perulangan While agar menu dapat dipilih berulang kali sampai kita memilih untuk selesai.

Fitur yang digunakan dalam program ini meliputi:

1. Tampilkan data, digunakan untuk melihat dan menampilkan isi dictionary buku.
2. Tambahkan data penerbit, digunakan untuk menambahkan data baru berupa penerbit ke dalam dictionary buku.
3. Ubah penulis, digunakan untuk mengubah data penulis yang sekarang dengan yang baru.
4. Hapus penerbit, digunakan untuk menghapus data penerbit dari dictionary buku.
5. Selesai, digunakan untuk menghentikan seluruh proses perulangan ketika kita sudah selesai menggunakan program.

Dibagian akhir terdapat tampilan data dictionary buku sebelum dan sesudah dilakukan perubahan agar kita bisa melihat hasil pengelolaan yang telah dilakukan.
